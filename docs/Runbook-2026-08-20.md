מה שנעשה, לפי הסדר:

**שני ממצאים בדרך:**

Payload בשליטה, והיא דלוקה מחוץ לפרודקשן. לכן כל `npm run dev` שינה את
מבנה בסיס הנתונים בשקט. עכשיו זה מוצהר במפורש.

הרפטיציה על עותק **דולגה במכוון** — אין `pg_dump` על המכונה, והפעולה היא
שורה אחת בבסיס נתונים מקומי שאפשר לבנות מחדש. **על הפרודקשן לחזור על
הרפטיציה**, שם הנתונים לא ניתנים לשחזור.

## 4. gates — ✓ ירוק

`generate:types` ✓ · `typecheck` ✓ · `lint` ✓ · `test` 241 ✓ · `build` ✓

רץ אחרי כל פרוסה, ותפס משהו בשלוש מהן. **תריץ אותו אחרי כל שינוי, לא
תצבור שניים-שלושה.**

היסטוריית מה שנתפס, כי כל אחד מהם היה דבר שקריאה סטטית דיווחה עליו כתקין:

**מה שנתפס ותוקן:** חמישה אתרי קריאה ל-`buildConferenceDescriptor` /
`buildOpeningDescriptor` בקבצי הבדיקות. הסריקה הידנית שלי כיסתה `src/`
בלבד; ה-typecheck מצא אותם. זו הסיבה ש-gates הוא הבדיקה ולא קריאה
סטטית של הקוד.

**מה שנשאר:** שני snapshots באנגלית. ה-diff מכיל בדיוק שישה שינויים —
`נטעים` → `Netaim` בניווט, בפוטר ובשורת הזכויות, בשתי החוויות.
**שני ה-snapshots בעברית עברו**, וזו ההוכחה שהשינוי תלוי-שפה ולא החלפה
גלובלית. זה גם בדיוק הבאג שדוח 15 הזהיר מפניו — שעדכון ה-baseline
יקפיא מותג עברי באתר האנגלי.

עודכן ב-`vitest -u`. **הכל ירוק, כולל `npm run build`.**

**מה שטבלת המסלולים גילתה:** העמודים האישיים עדיין מסומנים `●` ולא `ƒ`,
בניגוד למה שדוח 16 §4 טוען. **אין דליפה** — נבדק מול פלט הבנייה: אין
קובץ `.html` על הדיסק לאף מסלול אישי, ואין רישום ב-`prerender-manifest.json`.
הסימן `●` מגיע מ-`generateStaticParams` על מקטע השפה.

הוספתי בדיקה שבודקת את הארטיפקט ולא את הסימן, והוספתי תיקון מתוארך
לדוח 16.

**הגרסה הראשונה שלה נפלה על `/he` ו-`/en`, והיא זו שהייתה שגויה** — היא
ספרה כל מפתח ב-`prerender-manifest.json` כעמוד prerendered. הנתונים
בפועל: **אפס גופי תגובה** (`.html` או `.rsc`) בכל `.next/server/app`,
והרישום עבור `/he` הוא `{}` ריק. `routes: ['/he','/en']` זו המנייה של
`generateStaticParams`, לא תגובה שמורה. הבדיקה תוקנה לשאול את השאלה
הנכונה.

אחרי בנייה:

```bash
npm run test
```

הבדיקה קוראת את `.next/` — בעץ נקי היא מדלגת, אחרי build היא אמיתית.
